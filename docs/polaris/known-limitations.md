# Polaris RESTCATALOG Known Limitations

- 기준: `feature/polaris-restcatalog` Phase 1–6 (`67cf10e4c` … `6d2f6f4e9` + Phase 6 작업 tree), Apache Polaris `1.1.0-incubating`, Iceberg `1.7.0-5f7c992-20250730084652-3bf8b99` (Dremio fork).
- 출처: [progress.md](progress.md), [phase3-oauth-catalog.md](phase3-oauth-catalog.md), [storage.md](storage.md), [security.md](security.md), [compatibility-matrix.md](compatibility-matrix.md), [phase1-analysis.md](phase1-analysis.md) Gap 목록. Phase 5 E2E 결과([test-results.md §5](test-results.md#5-phase-5--실제-e2e--regression))와 Phase 6 수정·최종 smoke([test-results.md §7](test-results.md#7-phase-6--최종-통합--release-readiness))를 반영했다. 괄호 안 `A-…`/`B-…`/`C-…`/`D-…`/`E-…`/`F-…`/`U-…`/`I-…`는 그 표의 시나리오 번호다.
- Status: 작업 정의(spec "결과 상태")의 네 값 `PASS`, `FAIL`(알려진 결함), `ENVIRONMENT_BLOCKED`(환경 제약으로 실행하지 못함), `NOT_SUPPORTED`(설계상 또는 현재 미지원) 중 하나만 쓴다. 괄호 안은 비고(제약, 이 branch에서 고침, 근거, 이유)이며 별도 상태가 아니다. 한 행이 하위 항목 여럿을 묶으면 `/`로 나눠 각각 네 값 중 하나를 쓴다. 이 작업에서 실행하지 않은 항목은 지원한다고 주장하지 않으므로 `NOT_SUPPORTED (검증하지 않음: <이유>)`로, 환경이 없어 실행하지 못한 항목은 `ENVIRONMENT_BLOCKED`로 적는다. 관찰만 한 upstream/harness 동작도 같은 규칙을 따른다.
- 구분: **plugin**(이 branch의 `plugins/icebergcatalog`에서 고칠 수 있음), **kernel**(`sabot/kernel`, `dac` 등 공통 framework), **upstream**(Iceberg library / Polaris 동작·정책), **환경**.
- 모든 secret은 placeholder다.
